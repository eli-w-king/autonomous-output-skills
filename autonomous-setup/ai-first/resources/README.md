# Your workshop folder

This folder is everything the AI-First Design Workshop setup put on your computer, in one place.

| What | Where |
| --- | --- |
| Your copy of the Excalidraw case study | `excalidraw-case-study/` (and on GitHub, in your account) |
| The practice docs: the brief, the PM follow-up, and the research practice files | `excalidraw-case-study/workshop/` |
| The prompts for the hands-on part | `resources/prompts.md` |
| A one-page cheat sheet | `resources/cheat-sheet.md` |
| The 16 workshop settings | `resources/workshop-settings.jsonc` |
| The skills, as downloaded | `autonomous-output-skills/` |
| Tools the setup added (only the ones your computer was missing) | `tools/` |
| What the setup added, for the uninstall | `.setup/installed.md` |

The practice docs are fictional practice material for the workshop. They aren't Excalidraw's roadmap or research.
